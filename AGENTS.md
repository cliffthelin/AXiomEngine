# Reversa

> Reverse engineering framework installed in this project.

## How to use

Type `reversa` to activate Reversa and start or resume project analysis.

## Activation behavior

When the user types `reversa` alone in a message:

1. Activate the `reversa` skill available in `.agents/skills/reversa/SKILL.md`
2. Read the SKILL.md file in its entirety and follow Reversa's instructions exactly.

## Non-negotiable rule

Never delete, modify, or overwrite pre-existing files from the legacy project.
Reversa writes **only** to `.reversa/` and `_reversa_sdd/`.
