# Purpose and Scope

This document defines how authoritative intent is structured and externalized into Markdown artifacts. 

### R-PDD-MD-001
Prompts Select Intent, Markdown Contains It Prompts are selectors of intent, not containers of intent. Prompts must reference durable, authoritative artifacts that live in the repository. If a prompt relies on tribal knowledge or chat history, it is not production-ready. 

### R-PDD-MD-002

### R-PDD-MD-003
Stable Identifiers Authoritative Markdown must define named rules or requirement IDs (e.g., R-PDD-MD-003) rather than relying on narrative references. This allows prompts to explicitly force alignment.
