# Inference Worker Contract (v1.1.0)

## Objective
Execute high-rationale governance missions using large-scale LLMs (e.g., Qwen 3.6:27B) while adhering to GPU resource policies and producing audit-defensible evidence.

## Pre-execution Checks (Governance Gate)
Before initiating any LLM inference, the worker MUST:
1. **Consult Provider Registry**: Read `docs/audit/gpu_provider_report.json` or invoke `gpu_provider_registry.py`.
2. **Verify Hardware**: Confirm the Tesla P40 is present and its `utilization.gpu` is < 80%.
3. **Verify Model**: Confirm the target model (e.g., `qwen3.6:27b`) is loaded in Ollama.
4. **Reserve Resources**: (Logical) Mark the mission as "IN_PROGRESS" in the mission log to prevent resource collisions.

## Execution Requirements
1. **Context Injection**: Use the full content of the `scope` files as the primary context.
2. **Skill Application**: Load the specified Reversa skill from `skills/reversa/<skill>/SKILL.md`.
3. **Timeout Policy**: Set a minimum timeout of 600 seconds for inference to accommodate 27B+ models on the P40.

## Output: Evidence Pack
The worker MUST produce a `mission_evidence.json` containing:
- `mission_id`: Unique UUID for the run.
- `timestamp`: ISO8601 start/end times.
- `scope`: File paths audited.
- `source_hash`: SHA256 of the source code audited.
- `skill`: The name of the Reversa skill applied.
- `model`: The model used (e.g., `qwen3.6:27b`).
- `gpu_metrics`: 
  - `hardware`: (e.g., Tesla P40)
  - `vram_used_mib`: Peak VRAM usage during the run.
- `llm_rationale`: The raw text generated by the model.
- `status`: SUCCESS | FAILED | BLOCKED.

## File Locations
- **Report**: `docs/audit/mission_evidence_<timestamp>.json`
- **Markdown Summary**: `docs/audit/mission_report_<timestamp>.md`
