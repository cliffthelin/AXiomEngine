---

## How the user responds

The user should:
1.  Fill in the `**Answer:**` field for each question
2.  Notify the Revisor when finished (type `reversa` or "answered the questions")

---

## How the Revisor processes the answers

After receiving notification from the user:
1.  Read the entire file
2.  For each question with a filled answer:
    *   Update the corresponding spec
    *   Reclassify the item based on the answer (🔴→🟢 or 🔴→🟡)
    *   Mark the question as `✅ Answered` above the Answer field
3.  For unanswered questions: keep as 🔴 in the final report
4.  Update `confidence-report.md` with the new percentages
