# Active ARCHON-REFERENCES Checklist: repo-init.md

- [ ] G-ARCHON-REFERENCES-REPO-INIT-001: What each directory is for: (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-002: `commands/` — Reusable prompt templates used by `command:` workflow nodes. Committed to git. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-003: `workflows/` — YAML workflow definitions. Committed to git. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-004: `scripts/` — Named TypeScript/JavaScript (bun) or Python (uv) scripts referenced by `script:` nodes. Extension determines runtime: `.ts`/`.js` → bun, `.py` → uv. Committed to git. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-005: `mcp/` — MCP server JSON configs. Usually checked in with `$ENV_VAR` references; avoid hardcoding secrets. Some teams gitignore this and rely entirely on env expansion. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-006: `state/` — Workflowwritten crossrun state (e.g. the `repotriage` dedup log). Always gitignore — these are runtime artifacts, not source. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-007: `config.yaml` — Repospecific defaults (assistant, worktree settings, etc.). Committed to git. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-008: `.env` — Reposcoped Archon env (loaded with `override: true` at boot). Do NOT commit. This is different from the target repo's toplevel `.env` — that file belongs to the target project, and Archon strips its autoloaded keys from subprocess env before spawning AI to prevent leakage. See ThreePath Env Model below. (Section: Directory Structure)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-009: .env.local (Section: Worktree settings)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-010: To see bundled workflows: `archon workflow list` (Section: How Bundled Defaults Work)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-011: To override a default: Create a file with the same name in your repo's `.archon/workflows/` or `.archon/commands/`. Repo files take priority. (Section: How Bundled Defaults Work)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-012: To disable defaults: Set `defaults.loadDefaultWorkflows: false` or `defaults.loadDefaultCommands: false` in config. (Section: How Bundled Defaults Work)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-013: Where should you put what? (Section: Three-Path Env Model)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-014: API keys for Archon itself (`ANTHROPIC_API_KEY`, `CLAUDE_CODE_OAUTH_TOKEN`, `DATABASE_URL`, `SLACK_BOT_TOKEN`, etc.) → `~/.archon/.env` (shared across all repos) or `<cwd>/.archon/.env` (perrepo override). (Section: Three-Path Env Model)
- [ ] G-ARCHON-REFERENCES-REPO-INIT-015: Targetproject env that a workflow needs (`GH_TOKEN`, `DOTENV_PRIVATE_KEY`, etc.) → see [PerProject Env Injection](#perprojectenvinjection) below. (Section: Three-Path Env Model)
